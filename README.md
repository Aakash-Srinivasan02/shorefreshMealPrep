# Shore Fresh Meal Prep website redesign

This repository contains a refreshed static landing page for Shore Fresh Meal Prep.

## Files
- `index.html` – homepage structure and content
- `styles.css` – responsive styling and layout
- `script.js` – small mobile navigation behavior

## Preview locally
Open `index.html` in a browser, or use a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Purpose
This design focuses on:
- a stronger first impression
- clearer service positioning
- improved call-to-action flow
- mobile-friendly layout
- better trust and conversion cues for a meal prep business

## Notes
The current copy uses placeholder contact details and local ordering language based on the public information available for the business. These can be refined further once the client confirms exact menu, pricing, and delivery details.
